AI Disclosure

Our team has followed the AI Usage Policy for this project.

Tools used

How AI was used

  • Prior to the policy release we used AI for helping generate a skeleton node code (in a simialr format to labs) with TODO's and scaffolding for the project as well as some param files and launch files. In addition AI (Cursor and Claude) was used to help generate our README and some boilerpalte helper functions for interacting with action servers and the other nodes.
  • After the policy release we went back and rewrote much of the code including most of the core functions and algorithmic code and helper functions. Boilerpalte ROS plumbing was kept after the policy release but future nodes avoided this approach.
  • AI (Cursor and Claude) was also used to help us debug the code and the project overall, for brainstorming ideas and for general guidance.
  • AI (Cursor and Claude) was also used to build a sim environment in gazebo to help us test outside of the lab based on URDF models and xacro files from online.
  • AI (Cursor and Claude) was also used to help us connect the 2 PC's using ROS2 Domain Bridge and the YAML bridge to relay selected topics.

  • Formatting the final project website layout
